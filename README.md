# Артём — лендинги, боты, парсеры, скрипты

Статическая страница-визитка. Один файл `index.html`, без сборки и зависимостей.

## Деплой на Render

1. Перейти по ссылке: `https://render.com/deploy?repo=<url этого репозитория>`
2. Подтвердить создание сервиса — Render прочитает `render.yaml` и опубликует статический сайт.
3. Автодеплой: любой пуш в `main` пересобирает сайт.
